## Judgment calls and limitations
- Orchestrator fix: moving a report to in_progress now requires an assignee (server + UI). Without it an unassigned in-progress report could never be closed.
- Orchestrator fix: added labels for `feedback.created` (S7) and `maintenance.photos_purged` (S5) so the label test passes after merge.
- Admins cannot resolve directly anymore; they verify a staff request. Admins are not assignable, so admin-only work has no closing path by design.
- Approving needs a typed comment, which is the confirmation step; there is no extra modal.
