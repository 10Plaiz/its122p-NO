## Judgment calls and limitations
- Orchestrator: the draft key includes the user id so a shared phone never offers one citizen's draft to another.
- Orchestrator: the Edit button waits for the report's problems to load, so a failed load cannot look like "no problems".
- Orchestrator: FUNC-01 and VAL-06 samples gained `primary_problem_id: 1`, now required.
- In-app navigation is not blocked (BrowserRouter has no blocker); the draft covers that case on the new-report form. The edit form has no draft, only the unload warning and the Cancel confirmation.
- Dictation audio goes to the browser vendor's recognition service, not to KAMOTI.
