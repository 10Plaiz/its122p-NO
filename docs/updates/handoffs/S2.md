- Reverse geocoding stays on Nominatim so no extra Google API is needed.
- `DEMO_MAP_ID` is used unless `VITE_GOOGLE_MAPS_MAP_ID` is set (Advanced Markers need a map ID).
- No browser smoke test was run with a real key in this phase.
