## Judgment calls and limitations
- The server returns rows; the browser decides the columns, so an export never contains a hidden column.
- The PDF uses jsPDF's built-in Helvetica (WinAnsi): characters outside it, such as "→" or emoji in a title, print garbled in PDF only. CSV is unaffected. Embedding a Unicode font would add about 300 KB on demand.
- Page number stays in component state like the existing tables, not in the URL.
- Column choices live in the browser (localStorage), so they do not follow a person to another device.
